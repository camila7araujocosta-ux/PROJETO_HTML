# Projeto HTML - Coreia do Sul

## Sobre o Projeto

Este projeto foi desenvolvido para a disciplina de Desenvolvimento Front-End para Web, com o objetivo de apresentar informações sobre a Coreia do Sul.

O site contém conteúdos sobre história, geografia, cultura, gastronomia, turismo, tecnologia, K-pop, esportes, doramas e curiosidades do país.

## Tecnologias Utilizadas

- HTML5

## Estrutura do Projeto

- index.html
- historia.html
- geografia.html
- cultura.html
- culinaria.html
- turismo.html
- seul.html
- tecnologia.html
- kpop.html
- esportes.html
- doramas.html
- curiosidades.html

## Recursos Utilizados

- Tags semânticas
- Imagens com figure e figcaption
- Navegação entre páginas
- Formulários HTML
- Elementos multimídia
- Elementos interativos

## Objetivo

Apresentar informações relevantes sobre a Coreia do Sul utilizando apenas HTML, aplicando os conceitos estudados em aula.
